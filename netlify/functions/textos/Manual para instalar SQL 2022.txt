mano para Ágora

carpeta llamada SqlExpress. Accede a esta carpeta y ejecuta
SQLEXPR_x64_ENU.exe Si tienes una versión anterior de Ágora que no
contiene SQL2022, descarga una versión 8.5 o superior para encontrar
el instalador.

la instalación:

4. Instala Ágora. En el caso de que ya esté instalado, desinstálalo y
vuelve a instalarlo.

5. Abre el monitor del servicio de Ágora, accede a
herramientas/configurar servidor y pincha en crear base de datos.
La base de datos se habrá creado cuando el icono del ratón deje de
mostrar el reloj.

6. Una vez creada la base de datos, podremos lanzar un asistente de
configuración desde el monitor de Ágora en Datos/Asistente de
configuración, o recuperar un backup desde Datos/Copia de
seguridad/Recuperar
